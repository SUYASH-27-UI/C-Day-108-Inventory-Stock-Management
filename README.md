# C Day 108 – Inventory Stock Management System

## Description
A menu-driven inventory application developed in C to manage products, stock quantities and sales.

## Features
- Add products
- View inventory
- Search by product ID
- Update stock quantity
- Sell products
- Generate low-stock reports
- Save product records in a text file

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- File Handling

## Files
- `inventory.c` – Main program
- `inventory.txt` – Sample inventory data

## How to Run

```bash
gcc inventory.c -o inventory
./inventory
```

## Concepts Learned
Structures, arrays, functions, pointers, file handling, searching and stock management.
